# Nous — Ideas worth keeping

Ελληνικές κάρτες με ιδέες από βιβλία: τίτλος, σύντομο κείμενο, πηγή. Στατική PWA χωρίς framework και χωρίς build, που τρέχει σε GitHub Pages.

## Δομή

```
index.html             σελίδα
css/app.css            εμφάνιση (ανοιχτό/σκούρο θέμα)
js/app.js              όλη η λογική της εφαρμογής
js/store.js            μικρό IndexedDB, κοινό με τον service worker
sw.js                  offline cache + ημερήσια υπενθύμιση
manifest.webmanifest   στοιχεία εγκατάστασης (PWA)
icons/                 εικονίδια
content/index.json     λίστα με τα αρχεία θεμάτων
content/<θέμα>.json    οι κάρτες, ένα αρχείο ανά θέμα
content/journeys.json  οι Διαδρομές
tools/check-content.js έλεγχος περιεχομένου
```

## Προσθήκη καρτών

Κάθε αρχείο θέματος έχει αυτή τη μορφή:

```json
{
  "topic": "Συνήθειες",
  "sources": [
    {
      "id": "atomic",
      "title": "Atomic Habits",
      "author": "James Clear",
      "ideas": [
        { "h": "Τίτλος ιδέας", "b": "Σύντομο κείμενο." }
      ]
    }
  ]
}
```

- **Νέα κάρτα:** πρόσθεσέ τη **στο τέλος** της λίστας `ideas` μιας πηγής. Κάθε κάρτα αναγνωρίζεται ως `<id πηγής>:<θέση>` (π.χ. `atomic:0`). Αν αλλάξεις τη σειρά ή σβήσεις κάρτες, μετακινείται η πρόοδος των χρηστών και χαλάνε οι Διαδρομές.
- **Νέο βιβλίο:** πρόσθεσε νέο αντικείμενο στο `sources`, με `id` που δεν υπάρχει ήδη (λατινικά, χωρίς κενά).
- **Νέο θέμα:** φτιάξε `content/<όνομα>.json` και βάλε το όνομα του αρχείου στο `content/index.json`.
- **Διαδρομές:** στο `content/journeys.json`, η λίστα `ideas` κρατά ids καρτών με τη σειρά ανάγνωσης.

Πριν ανεβάσεις αλλαγές, τρέξε:

```bash
node tools/check-content.js
```

Οι χρήστες βλέπουν το νέο περιεχόμενο στο δεύτερο άνοιγμα της εφαρμογής: ο service worker δείχνει πρώτα ό,τι έχει αποθηκευμένο και το ανανεώνει στο παρασκήνιο. Όταν αλλάζεις κώδικα (HTML/CSS/JS), άλλαξε και το `VERSION` στο `sw.js`.

## Τοπική εκτέλεση

```bash
python -m http.server 8000
```

και άνοιξε http://localhost:8000. Ο service worker θέλει `localhost` ή `https`.

## Σημειώσεις

- Η πρόοδος, τα vaults και οι δικές σου ιδέες μένουν στο `localStorage` της συσκευής. Από το Προφίλ μπορείς να κάνεις εξαγωγή και εισαγωγή αντιγράφου.
- **Υπενθύμιση:** δεν υπάρχει διακομιστής push. Όταν η εφαρμογή είναι εγκατεστημένη σε Android/Chrome, ο service worker ελέγχει μέσω Periodic Background Sync. Όσο η σελίδα είναι ανοιχτή, ένα χρονόμετρο πιάνει την ακριβή ώρα. Το πότε θα ξυπνήσει την εφαρμογή το αποφασίζει ο browser, οπότε η ειδοποίηση μπορεί να αργήσει. Δεν έρχεται αν έχεις ήδη πιάσει τον στόχο της ημέρας.
- Η ανάγνωση φωναχτά χρησιμοποιεί τις φωνές της συσκευής (Web Speech API, `el-GR`).
- Οι κάρτες είναι συνοπτικές παραφράσεις, όχι αποσπάσματα.
