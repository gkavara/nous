# Nous — Ideas worth keeping

Ελληνικές κάρτες με ιδέες από βιβλία: τίτλος, σύντομο κείμενο, πηγή. Στατική PWA χωρίς framework και χωρίς build, που τρέχει σε GitHub Pages.

## Δομή

```
index.html             σελίδα
css/app.css            εμφάνιση (ανοιχτό/σκούρο θέμα)
js/app.js              όλη η λογική της εφαρμογής
js/store.js            μικρό IndexedDB, κοινό με τον service worker
js/themes.js           χρώματα ανά θέμα (εφαρμογή, Instagram, έλεγχος αντίθεσης)
js/story.js            εικόνα story 1080x1920 για «Κοινοποίηση ως εικόνα»
sw.js                  offline cache + ημερήσια υπενθύμιση
manifest.webmanifest   στοιχεία εγκατάστασης (PWA)
icons/                 εικονίδια
fonts/                 Literata και Commissioner (woff2, άδεια OFL), fonts.css
content/index.json     λίστα με τα αρχεία θεμάτων
content/<θέμα>.json    οι κάρτες, ένα αρχείο ανά θέμα
content/journeys.json  οι Διαδρομές
content/published-ids.json  όλα τα ids που έχουν δημοσιευτεί + τα αποσυρμένα
content/legacy-ids.json  αντιστοίχιση παλιών ids (θέση) σε νέα, για μεταφορά προόδου
tools/check-content.js έλεγχος περιεχομένου
tools/make-posts.js    γεννήτρια carousel για Instagram
tools/ig-template.html εγκεκριμένο οπτικό στυλ για Instagram
```

## Προσθήκη καρτών

Κάθε αρχείο θέματος έχει αυτή τη μορφή:

```json
{
  "topic": "Συνήθειες",
  "sources": [
    {
      "id": "atomic",
      "title": "Atomic Habits",
      "author": "James Clear",
      "ideas": [
        { "id": "atomic-titlos-ideas", "h": "Τίτλος ιδέας", "b": "Σύντομο κείμενο." }
      ]
    }
  ]
}
```

- **Νέα κάρτα:** πρόσθεσέ τη όπου θέλεις μέσα στη λίστα `ideas` μιας πηγής, με δικό της `id`. Το id είναι μοναδικό σε όλο το περιεχόμενο, με πεζά λατινικά, αριθμούς και παύλες. Η σύμβαση είναι `<id πηγής>-<τίτλος σε λατινικά>`, π.χ. `atomic-o-kanonas-ton-dyo-lepton`.
- **Μην αλλάζεις ποτέ το id μιας κάρτας που έχει δημοσιευτεί.** Σε αυτό είναι δεμένη η πρόοδος των χρηστών, τα vaults τους και οι Διαδρομές. Τη σειρά, τον τίτλο και το κείμενο μπορείς να τα αλλάζεις ελεύθερα.
- **Νέο βιβλίο:** πρόσθεσε νέο αντικείμενο στο `sources`, με `id` που δεν υπάρχει ήδη (λατινικά, χωρίς κενά).
- **Νέο θέμα:** φτιάξε `content/<όνομα>.json` και βάλε το όνομα του αρχείου στο `content/index.json`.
- **Διαδρομές:** στο `content/journeys.json`, η λίστα `ideas` κρατά ids καρτών με τη σειρά ανάγνωσης.
- Το `content/legacy-ids.json` χρειάζεται μόνο για συσκευές που κράτησαν πρόοδο από την πρώτη έκδοση, όταν οι κάρτες αναγνωρίζονταν από τη θέση τους. Μην το αλλάζεις.

Πριν από κάθε push, τρέξε τον έλεγχο. Μία εντολή ελέγχει τα πάντα:

```bash
node tools/check-content.js
```

Ο έλεγχος αποτυγχάνει αν:
- κάποια κάρτα δεν έχει id ή έχει διπλό ή μη έγκυρο id,
- μια Διαδρομή δείχνει σε κάρτα που δεν υπάρχει,
- λείπει από το περιεχόμενο κάποιο id του `content/published-ids.json` που δεν έχει καταχωριστεί ως αποσυρμένο,
- κάποιο θέμα δεν έχει χρώματα ή έχει χαμηλή αντίθεση,
- κάποια κάρτα δεν χωράει στο carousel του Instagram ή στο story της εφαρμογής ούτε με κείμενο 36px.

Ο έλεγχος μεγέθους τρέχει μέσα από το `tools/make-posts.js --check` και χρειάζεται Chrome ή Edge. Τρέχει μόνο όταν το υπόλοιπο περιεχόμενο είναι σωστό. Αν δεν έχεις browser, το `--no-fit` τον παραλείπει.

Όταν ο έλεγχος περνάει, προσθέτει μόνος του τα νέα ids στη λίστα `published` του `content/published-ids.json`. Ανέβασε το αρχείο μαζί με τις κάρτες. Με `--dry-run` κάνει μόνο τον έλεγχο, χωρίς να γράψει τίποτα.

**Απόσυρση κάρτας.** Αν θέλεις να βγάλεις οριστικά μια κάρτα, σβήσ' τη από το αρχείο του θέματος και γράψ' τη στο `retired` με έναν σύντομο λόγο:

```json
"retired": {
  "atomic-oi-tesseris-nomoi": "Συγχωνεύτηκε με την atomic-to-1pct-kathe-mera"
}
```

Ένα αποσυρμένο id δεν ξαναχρησιμοποιείται: ο έλεγχος αποτυγχάνει αν εμφανιστεί πάλι στο περιεχόμενο ή αν το βάλεις σε Διαδρομή. Αν θέλεις να αλλάξεις το id μιας κάρτας, ουσιαστικά αποσύρεις το παλιό, και όσοι την είχαν διαβάσει ή κρατήσει τη χάνουν από την πρόοδό τους.

Οι χρήστες βλέπουν το νέο περιεχόμενο στο δεύτερο άνοιγμα της εφαρμογής: ο service worker δείχνει πρώτα ό,τι έχει αποθηκευμένο και το ανανεώνει στο παρασκήνιο. Όταν αλλάζεις κώδικα (HTML/CSS/JS), άλλαξε και το `VERSION` στο `sw.js`.

## Χρώματα θεμάτων

Κάθε θέμα έχει τρία χρώματα στο `js/themes.js`: βαθύ φόντο, κείμενο, τόνο. Είναι η σκοτεινή εκδοχή, ίδια με τις εικόνες Instagram. Η φωτεινή εκδοχή της εφαρμογής βγαίνει αυτόματα από αυτά. Για νέο θέμα, πρόσθεσε μια γραμμή εκεί. Ο έλεγχος περιεχομένου αποτυγχάνει αν κάποιο θέμα δεν έχει χρώματα ή αν η αντίθεση είναι χαμηλή, σε φωτεινό ή σκοτεινό θέμα. Τα όρια: 7:1 για το κείμενο, 4.5:1 για τον τόνο και το δευτερεύον κείμενο.

## Εικόνες για Instagram

```bash
node tools/make-posts.js --topic Στωικισμός --count 3 --title "Τρεις στωικές ιδέες για να *μη σε αγχώνει* ό,τι δεν ελέγχεις"
```

Βγάζει carousel 1080x1350 PNG στο `posts/<θέμα>-<ημερομηνία>/`: εξώφυλλο, μία εικόνα ανά κάρτα και κλείσιμο με ερώτηση. Βγάζει επίσης το `caption.txt` με τη λίστα των καρτών. Ο φάκελος `posts/` δεν ανεβαίνει στο GitHub.

- `--ids a,b,c` αντί για `--topic`: συγκεκριμένες κάρτες, με αυτή τη σειρά.
- `--title`: κείμενο εξωφύλλου (υποχρεωτικό). Το `*έτσι*` βγαίνει με το χρώμα τόνου.
- `--subtitle`, `--question`, `--cta`: γραμμή κάτω από τον τίτλο, ερώτηση και κείμενο κλεισίματος. Το `**έτσι**` βγαίνει έντονο.
- `--count`, `--from`: πόσες κάρτες του θέματος και από ποια.
- `--theme`, `--out`: χρώμα του carousel και όνομα φακέλου.
- `--check`: ελέγχει μόνο αν χωράει το κείμενο, χωρίς να φτιάξει εικόνες. Χωρίς `--topic`/`--ids` ελέγχει όλες τις κάρτες.

Αν το κείμενο μιας κάρτας δεν χωράει, μικραίνει μαζί με τον τίτλο. Το κείμενο φτάνει έως τα 36px, από 40px κανονικά. Αν πάλι δεν χωράει, η γεννήτρια σταματά και λέει ποια κάρτα φταίει, με id, θέμα και μήκος, χωρίς να γράψει εικόνες. Το ίδιο όριο ισχύει και για την «Κοινοποίηση ως εικόνα» στην εφαρμογή, όπου το κείμενο ξεκινά από 44px.

Τον έλεγχο μεγέθους τον κάνει και το `node tools/check-content.js`. Για να ελέγξεις μόνο ένα θέμα ή συγκεκριμένες κάρτες:

```bash
node tools/make-posts.js --check --topic habits
```

Χρειάζεται μόνο εγκατεστημένο Chrome ή Edge και δουλεύει χωρίς internet, με τις γραμματοσειρές του `fonts/`. Το στυλ διαβάζεται από το `tools/ig-template.html`, οπότε αλλαγές εκεί περνούν και στις νέες εικόνες.

## Τοπική εκτέλεση

```bash
python -m http.server 8000
```

και άνοιξε http://localhost:8000. Ο service worker θέλει `localhost` ή `https`.

## Σημειώσεις

- Η πρόοδος, τα vaults και οι δικές σου ιδέες μένουν στο `localStorage` της συσκευής. Από το Προφίλ μπορείς να κάνεις εξαγωγή και εισαγωγή αντιγράφου.
- **Υπενθύμιση:** δεν υπάρχει διακομιστής push. Όταν η εφαρμογή είναι εγκατεστημένη σε Android/Chrome, ο service worker ελέγχει μέσω Periodic Background Sync. Όσο η σελίδα είναι ανοιχτή, ένα χρονόμετρο πιάνει την ακριβή ώρα. Το πότε θα ξυπνήσει την εφαρμογή το αποφασίζει ο browser, οπότε η ειδοποίηση μπορεί να αργήσει. Δεν έρχεται αν έχεις ήδη πιάσει τον στόχο της ημέρας.
- Οι γραμματοσειρές είναι στο `fonts/` (υποσύνολα ελληνικών και λατινικών, μεταβλητό βάρος 400–700, SIL Open Font License, βλ. `fonts/OFL-*.txt`). Ο service worker τις αποθηκεύει μαζί με την υπόλοιπη εφαρμογή, οπότε δεν χρειάζεται καμία σύνδεση σε εξωτερικό διακομιστή.
- Η ανάγνωση φωναχτά χρησιμοποιεί τις φωνές της συσκευής (Web Speech API, `el-GR`).
- Οι κάρτες είναι συνοπτικές παραφράσεις, όχι αποσπάσματα.
